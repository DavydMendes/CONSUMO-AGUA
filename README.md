# 💧 Consumo de Água

## 🌱 Sobre o projeto

O projeto **Consumo de Água** foi desenvolvido em Python para classificar o perfil de consumo de água de diferentes tipos de imóveis.

O programa solicita o tipo de imóvel e o consumo mensal de água em metros cúbicos (m³). Com essas informações, o sistema apresenta uma mensagem de orientação de acordo com as regras definidas na atividade.

## 🎯 Objetivo

O objetivo do projeto é aplicar os conhecimentos de programação em Python, utilizando estruturas condicionais como `if`, `elif` e `else`, além dos operadores `and` e `or`.

## ⚙️ Funcionamento

O programa solicita ao usuário:

- 🏢 Tipo de imóvel: comercial
- 🏠 Tipo de imóvel: casa
- 🏢 Tipo de imóvel: apartamento
- 💧 Consumo mensal de água em m³

Após receber as informações, o programa verifica as condições e apresenta a classificação correspondente.

## 📊 Classificação

- 🏢 **Comercial:** tarifa comercial aplicada.
- 💧 **Apartamento com consumo menor que 10 m³:** consumo econômico.
- 🏠 **Apartamento ou casa com consumo de até 25 m³:** consumo moderado.
- ⚠️ **Outras situações:** consumo excessivo.
